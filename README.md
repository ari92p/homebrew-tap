# ari92p Homebrew tap

Homebrew casks for apps by [ari92p](https://github.com/ari92p).

```sh
brew install --cask ari92p/tap/display-volume-keys
```

| Cask | Description |
| --- | --- |
| [`display-volume-keys`](https://github.com/ari92p/display-volume-keys) | Control external display speaker volume with the Mac's keyboard volume keys |

The casks are updated automatically when a new release is published.
